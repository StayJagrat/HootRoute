# HootRoute web (PWA)

React + Vite PWA built from the Figma file. One design system (`src/styles/tokens.css`: Night and Day themes), four agent mascots (`public/mascots/`, generated by `npm run assets`), the owl logo (`public/brand/`, icons by `npm run icons`).

| Route | Who | What |
|---|---|---|
| `/welcome` | First visit | The four agents in the order they work: Guide → Checker → Rescuer → Head |
| `/plan` | Walker | Steps ① Route ② Check: ask the Head in plain words or pick two points, compare Fastest vs HootRoute, the Checker's verdict ("Good to go" / "Heads up") with findings, live listing check |
| `/walk` | Walker phone | Step ③: street-sign turns, voice, check-in countdown, rescue ladder + Call 911. Step ④: the Head's report |
| `/guardian/:walk` | Guardian (QR, no install) | Live map, full-screen alert, "I'm on it", Call 911, handoff packet, ladder status |
| `/shop/:place` | Shopkeeper | Open until / front light / safe haven → the route re-scores live |
| `/room` | Laptop on stage | Map, agent feed with a reason for every action, why-this-street, darkness debt, guardian QR, start stage walk, overnight audit |
| `/setup` | Walker, once | Guardian, backup contact, standing orders |
| `/` | Demo crew | Hub (first visit goes to `/welcome`; `/?hub` skips it) |

```bash
npm install
npm run dev        # :5173, proxies /api and /ws to the gateway on :8000
npm run build      # the gateway serves web/dist itself in production
```

Flags: `?agents=live|demo` (gateway agents or the offline demo engine), `?gps=real|replay` (labelled replay for indoor demos; stage replays start 300 m before the stop). `VITE_APP_NAME` renames the app.

Message contract: `src/lib/types.ts`. Agent names: `head`, `guide`, `checker`, `rescuer`.

Honesty rules in the UI: demo tape on every replay, simulated shops labelled, unknown hours shown as unknown, missing data shown as missing, 311 reports are drafts, no mascots on alert screens, HootRoute never dials 911.
