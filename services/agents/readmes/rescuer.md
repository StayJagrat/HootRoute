# HootRoute Rescuer

If a walker stops answering, the Rescuer climbs a ladder, waiting for someone to answer at each rung: live map link and SMS to the guardian, a phone call, then the backup contact, then a Call 911 button for people. It never dials 911 itself. Talk to the HootRoute Head in ASI:One.
