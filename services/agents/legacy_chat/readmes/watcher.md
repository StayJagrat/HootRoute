# Streetwise Watcher

During an active walk, Watcher asks the user to check in at an interval (the message is relayed by Scout in the chat) and, if the user stops replying past a deadline, asks the Rescuer to prepare a handoff packet. It contacts nobody else. Typed messages only: `WalkStart`, `WalkStop`, `CheckInAck`, `RescueTrigger`, `RescueDone`, `UserNotice`. Talk to Scout, not to Watcher.
