# Streetwise Reporter

Turns a complaint such as "broken light near Civic Center BART" into a **DRAFT** San Francisco 311 report saved as a local text file. It **never submits anything**: the user reviews and files it themselves. Talk to Scout (`report ...`), not to Reporter.
