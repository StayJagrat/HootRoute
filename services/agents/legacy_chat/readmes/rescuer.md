# Streetwise Rescuer

Triggered by the Watcher when a walker stops replying. Writes a **handoff packet** (walk, destination, route polyline, open places near the route, instructions) to a local file for the user's trusted contact. It **never contacts emergency services**, sends no calls or texts, and posts nothing anywhere. If you need emergency help, call 911. Talk to Scout, not to Rescuer.
